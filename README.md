A simple Subbuteo-themed timer for table soccer clubs, to have a common timer for all tables. 
Select the half time length (10, 12 or 15min) and press KICK OFF. 
There is a lag denoted by whistle sound, to give a few sec before the actual countdown begins. 
There is option for extra time also (2 different time lengths, 3 and 4min).
Click RESET if you want to reset of course. There is a speech sound saying "two minutes" when the crunch time starts (the last two minutes). 
Open the Web App using a Browser from any device, tablet or phone.
